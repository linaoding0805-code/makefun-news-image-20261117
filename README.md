One image summing up Tuesday 17 November 2026: a newspaper front page with
four stories — the Kerch Bridge span collapsing after a Ukrainian strike,
tankers mined in the Strait of Hormuz, the Xi–Trump–Putin meeting set for
Thursday in Shenzhen, and the Vulcan rocket failure that lost 40 Amazon
satellites. Illustrations are AI-generated; every headline and caption is
set in type, so the facts read exactly as reported.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies `entry.png` (1024×1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, so two runs write identical
bytes.
